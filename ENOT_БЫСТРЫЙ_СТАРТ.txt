┌─────────────────────────────────────────────────────────┐
│  ШАГ 1: РЕГИСТРАЦИЯ (5 минут)                          │
└─────────────────────────────────────────────────────────┘

1. Зайди на: https://enot.io
2. Нажми "Регистрация"
3. Заполни форму и подтверди email


┌─────────────────────────────────────────────────────────┐
│  ШАГ 2: СОЗДАЙ МАГАЗИН (5 минут)                       │
└─────────────────────────────────────────────────────────┘

1. Зайди в личный кабинет
2. Магазины → "Создать магазин"
3. Заполни данные:
   - Название: Luminar Shop
   - Описание: Игровой клиент
   - Сайт: твой-сайт.com

4. Запиши:
   
   📝 Shop ID: ______________
   
   🔑 Secret Key 1: ______________
   
   🔑 Secret Key 2: ______________


┌─────────────────────────────────────────────────────────┐
│  ШАГ 3: НАСТРОЙ URLS (3 минуты)                        │
└─────────────────────────────────────────────────────────┘

В настройках магазина укажи:

Result URL (POST):
https://твой-сайт.com/api/payment/result

Success URL:
https://твой-сайт.com/api/payment/success

Fail URL:
https://твой-сайт.com/api/payment/fail


┌─────────────────────────────────────────────────────────┐
│  ШАГ 4: ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ (3 минуты)                │
└─────────────────────────────────────────────────────────┘

🖥️ НА RENDER:

1. Dashboard → твой сервис → Environment
2. ДОБАВЬ:
   ✅ ENOT_SHOP_ID = твой_shop_id
   ✅ ENOT_SECRET_KEY = твой_ключ_1
   ✅ ENOT_SECRET_KEY_2 = твой_ключ_2

3. Нажми "Save Changes"


📦 НА VERCEL:

1. Dashboard → Settings → Environment Variables
2. Добавь 3 переменные выше
3. Запусти: vercel --prod


┌─────────────────────────────────────────────────────────┐
│  ШАГ 5: ПРОВЕРЬ (2 минуты)                             │
└─────────────────────────────────────────────────────────┘

1. Зайди на свой сайт
2. Купи подписку (тестовый режим)
3. Проведи платеж

✅ Работает? Готово!
❌ Не работает? Смотри логи
