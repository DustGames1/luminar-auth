Формат подписи Enot.io:
MD5(shop_id:amount:secret_key:order_id)

URL платежа:
https://enot.io/pay?m=SHOP_ID&oa=AMOUNT&o=ORDER_ID&s=SIGN

Успешный ответ на Result URL:
OK

Параметры Result URL (POST):
• merchant - Shop ID
• amount - Сумма
• order_id - ID заказа
• sign - Подпись
