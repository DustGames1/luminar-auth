# Настройка Robokassa для Luminar

## ✅ Преимущества Robokassa:
- Не требует ИП/самозанятости на старте
- Быстрая регистрация (5-10 минут)
- Комиссия 3-5% (выше чем ЮKassa, но проще подключить)
- Поддержка всех популярных способов оплаты

---

## 📝 Шаг 1: Регистрация в Robokassa

### 1.1 Создание аккаунта

1. Перейдите на https://auth.robokassa.ru/Registration
2. Заполните форму регистрации:
   - **ID Кабинета (Логин):** придумайте уникальный логин (например, `luminar_shop`)
   - **Почта администратора:** ваш email
   - **Пароль:** придумайте надёжный пароль
3. Поставьте галочки:
   - ✅ Я ознакомлен с соглашением с требованиями к сайту
   - ✅ Я согласен с политикой ПДн
   - ✅ Я согласен на передачу информации третьим лицам
   - ✅ Я ознакомлен с правилами обработки персональных данных
4. Нажмите **"Продолжить"**
5. Подтвердите email (придёт письмо с кодом)

### 1.2 Заполнение данных о магазине

После регистрации заполните:

**Основная информация:**
- **Название магазина:** Luminar (или ваше название)
- **Описание:** Продажа подписок на игровой клиент
- **Сайт:** `https://ваш-домен.vercel.app`
- **Категория:** Цифровые товары / Игры

**Контактные данные:**
- Ваш телефон
- Email для связи

**Реквизиты для выплат:**
- Номер карты или счёта (куда будут приходить деньги)
- ФИО владельца карты

## 🔑 Шаг 2: Получение API ключей

После одобрения аккаунта (обычно мгновенно):

1. Войдите в личный кабинет Robokassa
2. Перейдите в **"Технические настройки"** → **"Настройки магазина"**
3. Найдите и скопируйте:
   - **Идентификатор магазина (MerchantLogin)** - ваш логин
   - **Пароль #1** - для формирования подписи при отправке данных
   - **Пароль #2** - для проверки подписи при получении результата

### 2.1 Настройка Result URL и Success URL

В разделе **"Технические настройки"**:

1. **Result URL (POST):** `https://ваш-домен.vercel.app/api/payment/result`
   - Метод: POST
   - Это URL для уведомлений о платеже (обязательно!)

2. **Success URL:** `https://ваш-домен.vercel.app/api/payment/success`
   - Сюда перенаправляется пользователь после успешной оплаты

3. **Fail URL:** `https://ваш-домен.vercel.app/api/payment/fail`
   - Сюда перенаправляется при отмене платежа

4. Сохраните настройки

---

## 🔧 Шаг 3: Настройка переменных окружения

### На Vercel:

1. Откройте проект на https://vercel.com
2. Перейдите в **Settings → Environment Variables**
3. Добавьте переменные:

```
ROBOKASSA_LOGIN=ваш_логин_магазина
ROBOKASSA_PASSWORD1=ваш_пароль_1
ROBOKASSA_PASSWORD2=ваш_пароль_2
ROBOKASSA_TEST_MODE=false
```

**Для тестирования** (необязательно):
```
ROBOKASSA_TEST_MODE=true
```

4. Нажмите **Save**
5. Сделайте **Redeploy** проекта

### Локально (для разработки):

Создайте файл `.env` в корне проекта:

```env
ROBOKASSA_LOGIN=ваш_логин
ROBOKASSA_PASSWORD1=ваш_пароль_1
ROBOKASSA_PASSWORD2=ваш_пароль_2
ROBOKASSA_TEST_MODE=true
DATABASE_URL=ваша_база_данных
JWT_SECRET=ваш_jwt_secret
ADMIN_KEY=ваш_admin_key
```

## 🧪 Шаг 4: Тестирование

### Тестовый режим:

Robokassa имеет встроенный тестовый режим:

1. Установите `ROBOKASSA_TEST_MODE=true`
2. Создайте продукт в админ-панели
3. Создайте промокод (опционально)
4. Перейдите на `/buy`
5. Выберите продукт
6. Примените промокод (если есть)
7. Выберите "СБП / Карта"
8. Нажмите "Купить"
9. В тестовом режиме Robokassa покажет форму оплаты с кнопкой "Успешная оплата"
10. Нажмите её - подписка активируется автоматически!

### Боевой режим:

1. Установите `ROBOKASSA_TEST_MODE=false`
2. Redeploy на Vercel
3. Проверьте реальную оплату (можно минимальной суммой)

## 💰 Шаг 5: Комиссии и выплаты

### Комиссии Robokassa:

- **Стандартный тариф:** 3-5% от суммы платежа
- **Для малого бизнеса:** можно договориться о снижении
- **Минимальная сумма платежа:** 1 рубль
- **Подключение:** бесплатно

### Выплаты:

- **Периодичность:** ежедневно или по запросу
- **Минимальная сумма:** 100 рублей
- **Способы:** на карту, счёт, электронные кошельки
- **Срок:** 1-3 рабочих дня

## ⚠️ Важные моменты:

### Безопасность:

- **Никогда не коммитьте** `.env` файл в Git
- **Храните пароли** только в переменных окружения
- **Проверяйте подпись** в Result URL (уже реализовано)
- **Используйте HTTPS** для всех URL

### Result URL:

- **Обязательно настройте** Result URL в Robokassa
- Без него подписка **не активируется** автоматически
- Robokassa отправляет POST запрос на этот URL
- Ответ должен быть `OK{InvId}` для подтверждения

### Промокоды:

- Промокод применяется **до** создания платежа
- Скидка учитывается в сумме платежа Robokassa
- Количество использований уменьшается **после** оплаты
